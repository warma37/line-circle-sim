1实验观察任务

  1. 将 a 从 −1.6 缓慢拖到 3，观察对称直线 L′ 的转动方向，以及它与圆 C 的位置关系如何变化。
  2. 记录两次「恰好相切」时 a 的值（提示：1/3 与 3/2），观察相切时直线与圆公共点的个数。
  3. 在 a∈[1/3, 3/2] 内任意取值：L′ 始终与圆有公共点；在区间外取值：L′ 与圆相离。验证这一规律。
  4. 点击 a=1：此时 d=0，L′ 恰好过圆心，弦成为直径——说明 d 是本问题的唯一核心量。
核心结论：d ≤ 1 ⟺ 有公共点（含相切）；d > 1 ⟺ 相离。临界处 d = 1。

2方法溯源：对称代换为什么是 y → 2a − y

关于水平直线 y = a 的对称，代换 y → 2a − y 是充分必要条件，不是记忆技巧：设 P(x,y) 与 P′(x,y′) 关于 y=a 对称，则 y′=2a−y，解出 y=2a−y′，互为逆代换。

用它对本题做检验（这一步可以手算核对）：

AB：(a−3)x − 2y + 2a = 0
代换 y → 2a−y ⟹ (a−3)x + 2y − 2a = 0
即 L′：y = a − a−32x

注意 L′ 的解析式里，令 x=0 恒得 y=a——这就是「L′ 必过 B」的代数证据，与层②看到的几何事实完全一致。

命题演化的规律：把等式的解改成一个区间，就把一道求值题变成了一道范围题——这是高考题从「母题」生成「新题」最常见的改造手法。
未采用的选项说明：另有「弦长最大值」这一常见设问方向，本题区间内 a=1 时 d=0、弦长取得最大值 2r=2；但该方向与本题「存在公共点」的设问距离较远，故本页的变式改用了「恰有一个公共点」。

4思想方法总结

  • 数形结合：「存在公共点」这个几何语言，翻译成代数语言就是 d ≤ r；反之由 d ≤ r 画出图形，又能直观验证。
  • 化归与转化：对称直线问题不易直接处理，用代换 y→2a−y 化归为「求一条已知直线」；直线与圆的位置关系又化归为「点到直线的距离与半径比较」。两次化归，把陌生问题变成了两个公式。
  • 函数与方程思想：d 是 a 的函数 d(a) = |7a+2| / √((a−2)²+16)，求 a 的范围就是解不等式 d(a) ≤ 1。
  • 临界意识（本题最易失分处）：「恰好相切」是分界点，相切时 d = r；「有公共点」必须取到等号。丢等号、或多写端点，都源于临界状态没有单独讨论。

1变式的观察任务

  1. 先点 a=−1 与 a=1/3，观察两处恰好相切：l 与圆只有一个公共点，此时 d 恰好等于 r = 1。
  2. 再把 a 拖到 −1 与 1/3 之间（如 a=−0.3、a=0）：l 与圆有两个公共点，d < r。
  3. 把 a 拖到区间之外（如 a=−1.6、a=1）：l 与圆相离，d > r。
  4. 对比原题：原题问「存在公共点」得到的是区间 [1/3, 3/2]；本题问「恰有一个公共点」，答案只是那个区间的两个端点。体会设问方式如何决定答案形态。

2变式解答（对比原题，看差异在哪）

① 写出直线 AB
A(−4,2)，B(0,a)
AB：(2−a)x + 4y − 4a = 0
② 代换 y → 2a − y
l：(2−a)x − 4y + 4a = 0
即 y = a + 2−a4x
③ 求圆心到 l 的距离
d = |7a+2|√((a−2)²+16)
圆心 (−3,−2)、r = 1
④ 恰有一个 ⟺ d = r
|7a+2| = √((a−2)²+16)
⟹ 3a² + 2a − 1 = 0
a = −1 或 a = 1/3
与原题的差异：原题把母题的条件「相切」（d = r）放宽成「有公共点」（d ≤ r），于是答案从一个值变成一个区间；本变式保留了「相切」这个严格条件，所以答案仍然是离散的两个值。
易错提醒：① AB 的系数随 A 的坐标改变，不能套用原题的 (a−3)x − 2y + 2a = 0；②「恰有一个公共点」是 d = r，不是 d ≤ r，忘了这一点就会答成区间 [−1, 1/3]；③ 解 3a²+2a−1=0 时注意因式分解 (3a−1)(a+1)=0 的两根符号相反。
